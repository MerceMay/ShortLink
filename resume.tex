\textbf{高并发短链接服务系统（Java）} \hfill 2024.06 – 2024.12 \\
\textbf{项目描述}：设计并实现了一个高性能、高可用的短链接服务系统，支持海量短链接的生成、访问、统计和管理功能。系统通过分库分表、多级缓存和消息队列技术实现高并发访问场景下的性能优化，在压力测试中表现优异。
\begin{itemize}
    \item \textbf{分库分表与水平扩展}：基于ShardingSphere实现数据库分库分表策略，将短链接表和分组表按哈希算法水平分片为16张表，有效解决单表数据量过大问题，支持亿级短链接存储。采用唯一索引（full\\_short\\_url + del\\_time）保证短链接的唯一性，配合逻辑删除标记实现数据的软删除功能。
    \item \textbf{多级缓存架构}：设计并实现布隆过滤器+Redis多级缓存架构，有效解决缓存穿透和缓存击穿问题。使用Redisson布隆过滤器快速判断短链接是否存在，避免无效数据库查询；配合Redis缓存原始URL映射关系，访问热点数据QPS提升80\\%以上。通过读写锁机制保证缓存与数据库的数据一致性。
    \item \textbf{异步统计系统}：构建基于RocketMQ的异步统计系统，将短链接访问统计与业务逻辑解耦。通过消息队列异步采集访问数据（PV、UV、UIP），收集地域分布、设备类型、操作系统、浏览器、网络类型等多维度信息，消费者批量写入统计表。采用幂等性设计防止消息重复消费，保证统计数据的准确性。
    \item \textbf{分布式并发控制}：通过Redisson实现分布式锁机制，解决短链接生成的并发冲突问题。在创建短链接时，对同一后缀加锁，保证并发场景下同一短链接只能被一个请求创建成功，避免数据库唯一索引冲突。集成Sentinel实现接口级别的流量控制和熔断降级，保护核心接口免受突发流量冲击。
    \item \textbf{回收站与有效期管理}：设计回收站机制支持短链接的软删除和恢复功能，通过逻辑删除标记实现数据保护。引入RocketMQ延迟队列实现短链接有效期的自动化管理，定时检测并将过期链接移入回收站。提供按分组、创建时间、状态等多维度的分页查询接口，支持批量管理操作。
    \item \textbf{统计分析与可视化}：构建完整的数据统计和分析系统，实时记录短链接的访问数据。提供日访问量统计、地域分布热力图、设备类型占比、浏览器版本分布等多维度数据展示。支持按天、按周、按月的访问趋势分析，提供Top访问IP排名和访问记录明细查询，为运营决策提供数据支持。
    \item \textbf{短链接生成与跳转}：实现基于哈希算法的短链接生成策略，支持自定义后缀和随机生成两种模式。通过布隆过滤器预判断和数据库唯一索引双重保证短链接的唯一性。实现302临时重定向跳转，在跳转前异步记录访问信息，利用Hutool工具库解析User-Agent获取客户端设备、操作系统、浏览器等信息。
\end{itemize}
\textbf{技术栈}：Java 17、Spring Boot 3.0、MyBatis Plus、ShardingSphere、MySQL 8.0、Redis、Redisson、RocketMQ、Sentinel、Hutool、Docker、Nginx
