# 简历LaTeX内容使用说明

## 文件说明

`project-resume.tex` 文件包含了本项目的简历描述内容，采用LaTeX格式编写，可以直接复制到你的简历LaTeX文档中。

## 使用方法

1. 打开你的LaTeX简历文档
2. 在项目经验部分，将 `project-resume.tex` 文件的全部内容复制粘贴进去
3. 根据个人情况调整项目时间（当前为 2024.06 – 2024.12）
4. 编译LaTeX文档即可

## 内容概述

本简历内容简洁描述了短链接系统的以下核心功能和技术亮点：

1. **分库分表与水平扩展**：ShardingSphere实现16表水平分片，支持亿级数据存储
2. **多级缓存架构**：布隆过滤器 + Redis缓存，解决缓存穿透和击穿问题
3. **异步统计系统**：RocketMQ消息队列实现削峰，SETNX保证幂等性
4. **短链接生成并发控制**：分布式锁 + Sentinel流量控制
5. **回收站与分类查询**：软删除、恢复、多维度分页查询
6. **统计分析与可视化**：多维度统计展示和趋势分析
7. **短链接生成与跳转**：哈希算法 + Base62编码 + 域名白名单

## 技术栈

Java 17、Spring Boot 3.0、MyBatis Plus、ShardingSphere、MySQL 8.0、Redis、Redisson、RocketMQ、Sentinel、Hutool、Docker、Nginx
