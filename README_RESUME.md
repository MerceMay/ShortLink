# 简历LaTeX内容使用说明

## 文件说明

`project-resume.tex` 文件包含了本项目的简历描述内容，采用LaTeX格式编写，可以直接复制到你的简历LaTeX文档中。

## 使用方法

1. 打开你的LaTeX简历文档
2. 在项目经验部分，将 `project-resume.tex` 文件的全部内容复制粘贴进去
3. 根据个人情况调整项目时间（当前为 2024.06 – 2024.12）
4. 编译LaTeX文档即可

## 内容概述

本简历内容详细描述了短链接系统的以下核心功能和技术亮点：

1. **分库分表与水平扩展**：ShardingSphere实现16表水平分片，支持亿级数据存储
2. **多级缓存与防护架构**：布隆过滤器 + Redis缓存 + 空值缓存 + 双重判定锁
3. **异步统计系统**：RocketMQ消息队列实现削峰填谷，9张统计表记录多维度数据
4. **消息队列幂等性设计**：Redis SETNX实现三态标记机制，保证消息仅消费一次
5. **分布式锁与并发控制**：Redisson读写锁保护数据修改，支持高并发场景
6. **双写一致性策略**：先更新数据库后删除缓存，保证最终一致性
7. **流量控制与降级保护**：Sentinel实现QPS限流和熔断降级
8. **回收站与管理功能**：软删除、恢复、多维度分页查询
9. **统计分析与可视化支持**：多维度统计分析，支持地域热力图和趋势分析
10. **短链接生成与跳转优化**：哈希算法 + Base62编码 + 域名白名单

## 技术栈

Java 17、Spring Boot 3.0、MyBatis Plus、ShardingSphere 5.3、MySQL 8.0、Redis、Redisson 3.27、RocketMQ 2.3、Sentinel、Hutool、Jsoup、Fastjson2、Docker、Nginx
