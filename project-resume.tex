\textbf{高并发短链接服务系统（Java）} \hfill 2024.06 – 2024.12 \\
\textbf{项目描述}：设计并实现了一个高性能、高可用的短链接服务系统，支持海量短链接的生成、访问、统计和管理功能；系统通过分库分表、多级缓存、消息队列和流量控制等技术实现高并发访问场景下的性能优化和系统稳定性保障。
\begin{itemize}
    \item \textbf{分库分表与水平扩展}：基于ShardingSphere实现数据库分库分表策略，将短链接表（t\_link）按gid字段、路由表（t\_link\_route）按full\_short\_url字段、分组表（t\_group）按username字段采用HASH\_MOD算法水平分片为16张表，有效解决单表数据量过大问题，支持亿级短链接存储；采用唯一索引保证短链接的唯一性，配合逻辑删除标记（del\_flag、del\_time）实现数据的软删除功能，避免物理删除造成的数据丢失风险。
    
    \item \textbf{多级缓存与防护架构}：设计并实现布隆过滤器 + Redis多级缓存架构，有效解决缓存穿透、缓存击穿和缓存雪崩问题；使用Redisson布隆过滤器（初始容量1亿，误判率0.1\%）快速判断短链接是否存在，在跳转请求到达数据库前进行第一道防护，性能远超分布式锁搭配数据库查询方案；通过Redis缓存短链接与原始URL的映射关系，实现毫秒级访问响应；针对不存在的短链接设置空值缓存（30分钟过期），防止恶意请求造成缓存穿透；采用双重判定锁机制，在缓存失效场景下通过分布式锁控制并发访问，避免大量请求同时查询数据库导致的缓存击穿问题。
    
    \item \textbf{异步统计系统}：构建基于RocketMQ的异步统计系统，充分利用消息队列的"削峰"特性，将短链接访问统计与核心业务逻辑解耦，提升系统吞吐量；通过消息队列异步采集多维度访问数据（PV、UV、UIP），收集访问时间分布（按小时、星期统计）、地域分布（省市级定位）、设备类型、操作系统、浏览器版本、网络类型等统计信息，消费者异步写入9张统计表（访问统计、地域统计、操作系统统计、浏览器统计、设备统计、网络统计、访问日志、今日统计等）；实现完整的访问记录追踪，支持访问日志明细查询和Top IP排名分析。
    
    \item \textbf{消息队列幂等性设计}：通过Redis的SETNX操作实现消息消费幂等性控制，保障消息在一定时间内（2分钟）消费且仅消费一次；设计三态标记机制（0-正在处理、1-处理完成、未设置-未处理），消费端通过判断幂等标识确定消息处理状态，若消息处理中断则触发RocketMQ重试机制，确保统计数据的准确性和完整性；在异常场景下自动删除幂等标识，支持消息重新消费，保证数据最终一致性。
    
    \item \textbf{分布式锁与并发控制}：在短链接生成和更新场景中合理使用分布式锁机制，解决高并发下的数据一致性问题；创建短链接时提供两种实现方式：基于布隆过滤器快速判断的乐观创建（利用数据库唯一索引捕获冲突）和基于分布式锁的悲观创建（对整个生成流程加锁）；在更新短链接分组信息时，使用Redisson分布式读写锁保护数据修改操作，确保大量访问场景下的数据一致性；消费统计消息时使用读锁，保证统计操作与更新操作的并发安全。
    
    \item \textbf{双写一致性策略}：采用"先更新数据库，后删除缓存"的双写一致性策略，保障短链接缓存与数据库之间的数据一致性；在短链接创建时同步写入数据库和缓存；在更新操作中，先修改数据库记录，再主动删除相关缓存，由后续访问触发缓存重建，确保缓存数据与数据库保持最终一致性；针对有效期变更场景，智能删除空值缓存，避免过期短链接更新后仍无法访问的问题。
    
    \item \textbf{流量控制与降级保护}：集成Sentinel实现接口级别的流量控制和熔断降级，通过QPS限流（配置为1QPS用于演示，生产环境可根据实际情况调整）保护核心接口免受突发流量冲击；在短链接创建接口上配置流控规则，触发限流后通过自定义BlockHandler进行降级处理，向用户返回友好提示信息（"当前访问网站人数过多，请稍后再试"），保障系统在高并发场景下的稳定运行，防止服务雪崩。
    
    \item \textbf{回收站与管理功能}：设计回收站机制支持短链接的软删除、恢复和彻底删除功能，通过逻辑删除标记（enable\_status）实现数据保护，避免误删操作造成数据永久丢失；提供按分组标识（gid）、创建时间、启用状态等多维度的分页查询接口，支持批量管理操作；在分组变更场景下，采用逻辑删除旧记录并插入新记录的方式，配合路由表更新，保证分组迁移的原子性和数据一致性。
    
    \item \textbf{统计分析与可视化支持}：构建完整的数据统计和分析体系，实时记录短链接的访问数据，支持单链接和分组两个维度的统计查询；提供访问趋势分析（按日期统计PV、UV、UIP）、时间分布分析（按小时、星期统计）、地域分布热力图（基于高德地图API进行IP定位，精确到省市级）、设备类型占比（PC、Mobile等）、操作系统版本分布、浏览器版本分布、网络类型分布等多维度数据展示；支持访问记录明细查询（包含用户标识、IP、浏览器、操作系统、网络、设备、地理位置等完整信息）和Top访问IP排名，为运营决策提供数据支持。
    
    \item \textbf{短链接生成与跳转优化}：实现基于哈希算法（HashToBase62）的短链接生成策略，在原始URL后追加UUID保证唯一性，通过哈希运算和Base62编码生成6-8位短链接后缀；布隆过滤器预判断避免重复，最多重试10次确保生成成功；短链接跳转采用302临时重定向，支持有效期控制（永久有效或指定日期失效）；实现域名白名单机制，限制可跳转的目标网站范围，提升系统安全性；自动获取原始网站的favicon图标，提升用户体验；访问统计采用Cookie+Redis Set组合方案，精确判断UV和UIP的首次访问，避免重复计数。
\end{itemize}
\textbf{技术栈}：Java 17、Spring Boot 3.0、MyBatis Plus、ShardingSphere 5.3、MySQL 8.0、Redis、Redisson 3.27、RocketMQ 2.3、Sentinel、Hutool、Jsoup、Fastjson2、Docker、Nginx
