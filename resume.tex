\textbf{高并发短链接服务系统（Java）} \hfill 2024.06 – 2024.12 \\
\textbf{项目描述}：设计并实现了一个高性能、高可用的短链接服务系统，采用微服务架构，支持海量短链接的生成、访问、统计和管理功能。系统采用分库分表技术，通过多级缓存和消息队列实现高并发访问场景下的性能优化。
\begin{itemize}
    \item \textbf{微服务架构设计}：采用Spring Cloud微服务架构，将系统拆分为管理服务（Admin）、短链接服务（Project）、网关服务（Gateway）三大核心模块，通过Nacos实现服务注册与发现，实现服务间的解耦和独立扩展。
    \item \textbf{分库分表与数据分片}：基于ShardingSphere实现数据库分库分表策略，将短链接表和分组表按哈希算法水平分片为16张表，有效解决单表数据量过大问题，支持亿级短链接存储。采用唯一索引（full\\_short\\_url + del\\_time）保证短链接的唯一性，支持逻辑删除。
    \item \textbf{多级缓存与防穿透}：设计并实现布隆过滤器+Redis多级缓存架构，解决缓存穿透和缓存击穿问题。使用Redisson布隆过滤器快速判断短链接是否存在，配合Redis缓存原始URL映射关系，访问热点数据QPS提升80\\%以上。实现读写锁机制保证缓存一致性。
    \item \textbf{异步统计与消息队列}：构建基于RocketMQ的异步统计系统，将短链接访问统计（PV、UV、UIP）、地域分布、设备类型、操作系统、浏览器、网络类型等多维度数据采集解耦到消息队列，通过消费者批量写入统计表。采用幂等性设计防止重复消费，保证统计数据准确性。
    \item \textbf{分布式锁与流量控制}：实现分布式锁机制解决短链接生成的并发冲突问题。通过Redisson分布式锁保证同一短链接后缀在并发场景下只能被一个请求创建。集成Sentinel实现流量控制和熔断降级，保护核心接口免受流量冲击。
    \item \textbf{回收站与生命周期管理}：设计回收站机制支持短链接的软删除和恢复功能。引入延迟队列实现短链接的有效期管理，自动将过期链接移入回收站。提供按分组、时间、状态等多维度的分页查询功能。
    \item \textbf{监控与数据可视化}：构建完整的监控和统计分析系统，提供日访问量、地域分布热力图、设备占比、访问记录等多维度数据可视化。支持按天、按周、按月的访问趋势分析和Top访问IP统计。
\end{itemize}
\textbf{技术栈}：Java 17、Spring Boot 3.0、Spring Cloud、Nacos、ShardingSphere、MySQL 8.0、Redis、Redisson、RocketMQ、MyBatis Plus、Sentinel、Docker、Nginx
